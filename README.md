# Шестнадцатеричный вьюер (Hex-Viewer)

---

## Возможности программы
Программа поддерживает следующие опции командной строки в любом порядке:
* `-i file_name` — имя выводимого файла.
* `-o offset` — смещение от начала файла, с которого выводится содержимое (по умолчанию: 0).
* `-l size` — количество выводимых байт (по умолчанию: до конца файла).
* `-g size` — размер одного кусочка (группы) данных в байтах (по умолчанию: 1).
* `-n count` — количество кусочков, выводимых в одной строке (по умолчанию: 16).
* `-d dir` — имя директории, из которой нужно вывести все файлы.

При работе с размером группы `-g 1` в конце каждой строки выводится символьный (ASCII) вид прочитанных байт. Внутреннее представление многобайтовых групп (`-g > 1`) выводится в формате **Little-Endian** (младший байт справа). Преобразование байтов в шестнадцатеричные символы реализовано вручную (без использования спецификатора `%x` для самих байтов).

## Сборка проекта

Для сборки проекта используется кроссплатформенная система CMake:

```bash
# 1. Создать директорию для сборки
mkdir build
cd build

# 2. Сгенерировать файлы сборки
cmake ..

# 3. Скомпилировать проект
cmake --build .
